# TechSprint AI Chatbot

## Overview
An AI-powered chatbot built using Google Gemini, LangChain, and FAISS that delivers intelligent, context-aware responses through an interactive Gradio interface.

## Features
- Google Gemini LLM integration
- Retrieval-Augmented Generation using FAISS
- Interactive Gradio UI
- Modular and scalable architecture

## Tech Stack
- Python
- Google Colab
- Google Gemini API
- LangChain
- FAISS
- Gradio

## How to Run
1. Open `techsprint.ipynb` in Google Colab
2. Set the Google Gemini API key as an environment variable
3. Run all cells sequentially
